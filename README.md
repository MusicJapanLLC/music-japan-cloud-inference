# Music Japan Cloud Inference Lab

Public, isolated GitHub-hosted Linux compute lab for reproducible open-weight LLM experiments.

- **Only open models and public code.** No Music Japan private source, company DB, credentials, messages, or customer data.
- **Zero new charges and zero proprietary model inference credits.**
- GitHub public standard hosted runner CPU resources are free as documented by GitHub.
- Experimental GPU services (Kaggle/Colab/ZeroGPU/Lightning) are separate; no GPU allocation is claimed until verified.
- Actual model identity and quality must be measured; API-compatible shapes do not imply equivalence to closed-weight Claude models.
- Runner is ephemeral. The GitHub repository and source code persist, not an always-on free server.

Source of truth for private company R&D remains [Music Japan AI Mesh](https://github.com/MusicJapanLLC/music-japan-ai-mesh) and its authorized internal databases. This public lab does not access those sources.
